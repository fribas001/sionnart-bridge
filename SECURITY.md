# Security policy

Do not disclose security-sensitive issues in a public issue. Contact the
maintainer at `felipe.oliveiraribas@ugent.be` with a minimal description,
affected version, and reproduction details.

SionnaRT-Bridge launches a user-selected external Python executable and writes
scene and result files to a user-selected workspace. Users should only select
trusted executables, extensions, `.blend` files, and repositories.
