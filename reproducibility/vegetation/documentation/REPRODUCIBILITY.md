# Reproduction levels and scope

1. **Recalculate derived results.** Original metadata, CSV records and raw arrays (where retained) support the numerical summaries. `analyze_paper.py` verifies all 50 current foliage arrays and reruns the analyzers for 30 numerical-stability calculations and the native comparison. The original seed-ensemble summary is preserved rather than recomputed from its limited displayed paths/CIR list.
2. **Rerun frozen scenes.** All 50 foliage scenes and the two matched-stability inputs are preserved exports. The three benchmark inputs retain the exact original XML/PLY bytes. Rebased foliage XML files preserve the mesh bytes but have new XML hashes, recorded separately. The earlier 50+20+20 scenes are reconstructed exports and are identified as such. Their recorded selected-tree leaf area, wood area and leaf-component counts match reconstruction exactly. This checks the generating geometry but is not a substitute for a file-byte identity claim.
3. **Regenerate procedural geometry.** The packed Blender project, embedded Geometry Nodes, explicit discrete controls, original transforms and clean-scene setup script allow re-export without manual inference. Only the selected tree is exported. Generic historical scene-wide geometry totals can include another background tree; the per-object vegetation records identify the simulated tree and are the correct source for its descriptors.
4. **Repeat software integration.** The source archive, standalone native runner, benchmark harness, dependency versions, hardware record and checksums make the tested routes inspectable. The new `validation/` runs are packaging checks, separate from the original article observations. Reproduction on a second machine has not yet been performed.

The data demonstrate a procedural experiment workflow. They do not establish measured-channel accuracy, unbiased ecological sampling, universal numerical convergence, radio-map numerical agreement, or a measured reduction in human effort. The 50 generator states define a conditional ensemble. The five foliage sequences have coupled twig/leaf geometry; they are not a controlled biological abscission experiment.

Original archives include selected path displays and at most 96 CIR components per link in some JSON records. Use full NPZ arrays when present, or the recorded full-channel summary. Never infer missing weak-path power by summing a truncated display. A missing valid path has no finite physical dB gain; the historical -600 dB storage sentinel is treated as missing when plotting the exploratory ray sweep.

The model contains separately licensed third-party assets, documented in LICENSE.md. Existing proprietary runtime binaries, GPU drivers and unrelated local files are not included. The FAIR release steps that still require the authors are listed in the Zenodo deposit guide.
